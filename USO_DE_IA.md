# Use of Super Intelligence (SI) · Uso de Inteligencia Artificial

As required by the NASA Space Apps Challenge, this file states where and how SI tools were used in AEGIS.
*Tal como exige NASA Space Apps, este archivo indica dónde y cómo se usaron herramientas de IA en AEGIS.*

## 1. SI used to build the project (development)

| What | SI tool | How it was used |
| --- | --- | --- |
| **Source code** (C# Unity scripts and shaders, Python ground station and web panel, Rust ground station, Blender/FreeCAD scripts, PowerShell/Bash scripts) | **Claude** (Anthropic), through Claude Code | Generated and revised code from the team's design decisions, requirements and feedback; the team tested every feature by running it (builds, end-to-end tests). |
| **Documentation and text** (README, LEEME, ENLACE_ESPACIO_TIERRA, reports templates, this submission text, demo slide text) | **Claude** (Anthropic) | Drafted and edited from the team's instructions; reviewed by the team. |
| **Demo slides** (`docs/AEGIS_demo.pdf`) | **Claude** (Anthropic) | Slide layout and text generated by a script written with SI. Each slide carries a visible footer stating SI assistance; the PDF metadata says so too. **All images in the slides and README are real screenshots of the running project, not SI-generated images.** |

## 2. SI inside the product (runtime)

| Feature | SI model | Notes |
| --- | --- | --- |
| ASTRA's spoken and written answers | **Qwen2.5 3B** (Alibaba Cloud) running locally on **Ollama** | Answers are SI-generated at runtime. A rule-based medical engine computes the facts from the simulation; the LLM only rephrases them. The panel shows which source answered (local LLM or rule engine). |
| ASTRA's voice (audio) | **Piper TTS**, voice `es_AR-daniela-high` (neural text-to-speech) | All speech audio is synthesized by SI at runtime. Disclosed here and in [LICENCIAS_TERCEROS.md](LICENCIAS_TERCEROS.md). |
| Speech recognition (microphone) | **Whisper small** via **whisper.cpp** | Transcribes the user's voice locally. |

## 3. Not SI-generated

- Physiological model, link physics, error-correction, cryptography design and filters: designed by the team (code written with SI assistance, see section 1).
- 3D models: team's own models (astronaut suit, anatomy, habitat), FreeCAD/Blender models created by script, and the **Microsoft Rocketbox** avatar (MIT license, human-made).
- No NASA logos, flags or mission identifiers were generated or modified.

## Metadata

Commits created with SI assistance include the line `Co-Authored-By: Claude` in the git history. The demo PDF
metadata (Subject/Keywords) states "Developed with Super Intelligence (SI) assistance: Claude (Anthropic)".
